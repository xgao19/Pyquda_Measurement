\section{Purpose and File Map}

This note documents the hadron-independent one-point functions used to build
disconnected contributions to proton and pion energy-momentum tensor (EMT)
matrix elements.  The main implementation is
\begin{center}
  \code{pyquda\_measurement\_utils/Disconnected\_1pt\_EMT\_vibe\_develop.py}.
\end{center}
The Perlmutter application entry points are in
\begin{center}
  \code{application/EMT\_disconnected\_1pt/perlmutter}.
\end{center}
The shorter command-oriented workflow guide is
\begin{center}
  \code{docs/EMT\_disconnected\_1pt/EMT\_proton\_disconnected\_guide.md}.
\end{center}

The one-point workflows do not form hadron three-point functions by themselves.
They measure vacuum loop building blocks.  A disconnected hadron matrix element
is formed later by correlating these one-point loops with hadron two-point
functions on the same gauge ensemble.

\section{Conventions}

We work in Euclidean spacetime with four directions.  Mathematical formulas use
\(\mu,\nu,\rho = 1,2,3,4\), while Python loops use zero-based indices
\(\mu,\nu,\rho = 0,1,2,3\).  The temporal direction is the fourth Euclidean
direction.  PyQUDA stores local lattice fields in even-odd layout; the displayed
formulas suppress this storage detail.

For a spatial momentum transfer \(q\), the code constructs spatial phases with
\code{MomentumPhase.getPhases}.  In this note the phase is written as
\begin{equation}
  \Phi_q(x) = e^{i\mathbf{q}\cdot\mathbf{x}},
\end{equation}
where only the spatial coordinates are Fourier transformed and the time
coordinate \(t\) is kept explicit.

The spatial volume normalization used in the averaged HDF5 datasets is
\begin{equation}
  \Vthree = L_x L_y L_z.
\end{equation}
The raw per-source quark datasets are stored before this \(\Vthree\)
normalization.  The averaged quark and gluon datasets are volume-normalized.

\section{Quark One-Point Workflow}

The quark workflow is usually the first part to study.  It contains the
stochastic trace estimator, the hierarchical-probing source bookkeeping, the
\(\chi\)-type diagnostics, and the flowed quark EMT loop used in disconnected
analysis.

\subsection{Target Trace}

A disconnected quark loop has the schematic form
\begin{equation}
  L^q_{\Gamma}(q,t;\Tf)
  =
  \sum_{\mathbf{x}} \Phi_q(x)\,
  \Trsc\!\left[
    \Gamma[U(\Tf)](x)\,D^{-1}[U](x,x)
  \right],
  \label{eq:generic_trace}
\end{equation}
where \(D^{-1}\) is the quark propagator, \(\Gamma\) is the local operator
kernel, and \(\Trsc\) denotes spin-color trace.  Directly computing all diagonal
entries of \(D^{-1}(x,x)\) is too expensive, so the trace is estimated with
stochastic sources.

\subsection{Stochastic Trace Estimator}

Let \(\xi_r\) be a stochastic source vector whose spin-color-site components
satisfy
\begin{equation}
  \left\langle \xi_r \right\rangle_{\mathrm{noise}} = 0,
  \qquad
  \left\langle
    \xi_r(i)\,\xi_r^\dagger(j)
  \right\rangle_{\mathrm{noise}} = \delta_{ij}.
  \label{eq:noise_identity}
\end{equation}
Here \(i,j\) are combined site, spin, and color indices.  The code obtains
\begin{equation}
  \eta_r = D^{-1}\xi_r
  \label{eq:eta_def}
\end{equation}
from the Dirac inverter.  For any operator matrix \(A\),
\begin{align}
  \left\langle
    \xi_r^\dagger A\eta_r
  \right\rangle_{\mathrm{noise}}
  &=
  \left\langle
    \xi_r^\dagger A D^{-1}\xi_r
  \right\rangle_{\mathrm{noise}}  \\
  &=
  \sum_{i,j,k}
  A_{ij}\,(D^{-1})_{jk}\,
  \left\langle
    \xi^\dagger_{r,i} \xi_{r,k}
  \right\rangle_{\mathrm{noise}} \\
  &=
  \sum_{i,j} A_{ij}\,(D^{-1})_{ji}
  =
  \Tr(A D^{-1}).
  \label{eq:stoch_trace_derivation}
\end{align}
This is the Hutchinson trace-estimator logic used by the quark one-point
workflow.

\subsection{\texorpdfstring{\(Z_n\)}{Zn} Noise}

The ordinary stochastic scheme is selected with
\begin{equation}
  \code{noise\_scheme = zn}.
\end{equation}
Each component of \(\xi\) is drawn independently from
\begin{equation}
  \xi(i) \in
  \left\{
  \exp\!\left(\frac{2\pi i r}{n}\right)
  \;\middle|\;
  r = 0,1,\ldots,n-1
  \right\},
  \label{eq:zn_noise}
\end{equation}
where \(n=\code{n\_zn}\).  The EMT quark one-point workflow now defaults to
full-volume \(\mathbb{Z}_4\) noise.  Its counter-based generator hashes the
global four-dimensional coordinate, spin, color, configuration number,
base-noise index, and optional stream salt.  Consequently the global source is
reproducible and independent of the chosen MPI decomposition.

This counter construction fixes a serious failure mode of rank-local backend
random-number generators.  If every MPI rank resets an ordinary generator to
the same state \(s\), ranks with the same local lattice shape draw the same
array.  For a rank-local index \(\ell\),
\begin{equation}
  \xi_r(\ell)=F(s,\ell)=\xi_{r'}(\ell),\qquad r\ne r'.
\end{equation}
The corresponding distinct global sites \(x_r+\ell\) and \(x_{r'}+\ell\)
then have unit rather than vanishing noise covariance,
\begin{equation}
  \mathbb E_\xi\!\left[\xi^\ast(x_r+\ell)
  \xi(x_{r'}+\ell)\right]=1,\qquad r\ne r',
\end{equation}
so the required identity in Eq.~\eqref{eq:noise_identity} is not sampled.
This creates rank-periodic off-diagonal terms, can bias the stochastic trace,
and changes the global source when the MPI decomposition changes.  Mixing the
rank into the seed removes exact repetition only for one fixed process layout;
it still makes the source depend on the rank assignment.  The production
counter instead uses physical global coordinates and semantic keys, so the
same configuration, base index, and stream reconstruct exactly the same global
field for every MPI geometry.  Legacy backend-RNG loop data are therefore not
combined with counter-noise production data.

\subsection{Quark EMT Operator Implemented in Code}

The quark EMT kernel in the one-point code is the local bilinear with a
covariant derivative acting on the solution vector \(\eta\).  The implemented
per-source, pre-volume-normalized object is
\begin{equation}
  L^{q,(r)}_{\nu\mu}(q,t;\Tf)
  =
  -\frac{1}{2}
  \sum_{\mathbf{x}} \Phi_q(x)\,
  \xi_r^\dagger(x;\Tf)\,
  \gamma_\nu\,
  \Big[
    D_{+\mu} - D_{-\mu}
  \Big]\,
  \eta_r(x;\Tf).
  \label{eq:quark_loop_raw}
\end{equation}
This formula maps directly to
\code{\_get\_Tmunu\_symmetrized\_P\_Breit\_slice}.  In code:
\begin{verbatim}
tmp = U_f.pure_gauge.covDev(eta, mu) - U_f.pure_gauge.covDev(eta, mu + 4)
Y = contract("ab,...bc->...ac", D_gammas_local[nu], tmp.data)
complex_field = contract("...sc,...sc->...", xi.data.conj(), Y)
Tmunu[nu, mu] += -0.5 * impose_P_Breit_slice(...)
\end{verbatim}
The first tensor index is \(\nu\), because the gamma matrix \(\gamma_\nu\) is
applied after choosing the derivative direction \(\mu\).  This is why the code
fills \code{Tmunu[nu, mu]} before symmetrization.

\subsection{Symmetrization}

The EMT tensor is symmetrized after all unsymmetrized components have been
accumulated:
\begin{equation}
  L^q_{\mu\nu}
  \leftarrow
  \frac{1}{2}\left(L^q_{\mu\nu} + L^q_{\nu\mu}\right).
  \label{eq:quark_sym}
\end{equation}
The code then sets both entries equal.  The HDF5 writer stores only the upper
triangle \(\mu\leq\nu\), with dataset names \code{T11}, \code{T12}, \ldots,
\code{T44}.  The lower triangle should be reconstructed by symmetry if needed.

\subsection{Noise Average and Volume Normalization}

For \(N_{\mathrm{eff}}\) effective sources, the averaged quark one-point loop is
\begin{equation}
  L^q_{\mu\nu,\mathrm{avg}}(q,t;\Tf)
  =
  \frac{1}{\Vthree}\,
  \frac{1}{N_{\mathrm{eff}}}
  \sum_{r=1}^{N_{\mathrm{eff}}}
  L^{q,(r)}_{\mu\nu}(q,t;\Tf).
  \label{eq:noise_volume_avg}
\end{equation}
The code stores both the raw per-source data and the averaged
volume-normalized data:
\begin{align}
  \code{raw/Tmunu\_pervec}
  &\leftrightarrow
  L^{q,(r)}_{\mu\nu}(q,t;\Tf),
  \\
  \code{avg/Tmunu/Tij}
  &\leftrightarrow
  L^q_{ij,\mathrm{avg}}(q,t;\Tf).
\end{align}

\subsection{\texorpdfstring{\(\chi\)}{CHI} Diagnostics}

The quark workflow also writes two scalar diagnostics:
\begin{align}
  \chi_0^{(r)}(q,t;\Tf)
  &=
  \sum_{\mathbf{x}}\Phi_q(x)\,
  \xi_r^\dagger(x;\Tf)\,\eta_r(x;\Tf),
  \label{eq:chi0}
  \\
  \chi_1^{(r)}(q,t;\Tf)
  &=
  \sum_{\mathbf{x}}\Phi_q(x)\,
  \xi_r^\dagger(x;\Tf)\,\xi_r(x;\Tf).
  \label{eq:chi1}
\end{align}
\(\chi_0\) is the stochastic scalar trace estimate.  \(\chi_1\) checks the
noise normalization.  In code these are the two entries of \code{CHI}:
\begin{verbatim}
dot_xi_eta = contract("etzyxbc,etzyxbc->etzyx", xi.data.conj(), eta.data)
CHI[0] = impose_P_Breit_slice(U_f, dot_xi_eta, phases_3pt)

dot_xi_xi = contract("etzyxbc,etzyxbc->etzyx", xi.data.conj(), xi.data)
CHI[1] = impose_P_Breit_slice(U_f, dot_xi_xi, phases_3pt)
\end{verbatim}
The averaged HDF5 dataset \code{avg/CHI} is divided by \(\Vthree\), just like
the averaged quark EMT datasets.

\subsection{Ringed-Fermion Kinetic Normalization}

The raw \code{CHI} datasets are diagnostics, not the ringed-fermion
normalization itself.  The kinetic observable is already contained in the
zero-momentum diagonal quark EMT components.  For each effective stochastic
source \(r\), the implementation forms
\begin{equation}
  K_r(\Tf,\tau)
  =-\frac{2}{\Vthree}\sum_{\mu=1}^{4}
  L^q_{\mu\mu,r}(q=0,\tau;\Tf)
  =\frac{1}{\Vthree}\sum_{\mu,\mathbf{x}}
  \xi^\dagger(x;\Tf)
  \gamma_\mu
  \left[D_{+\mu}-D_{-\mu}\right]
  \eta(x;\Tf).
  \label{eq:ringed_building_block}
\end{equation}
No new inversion, fermion-flow update, covariant derivative, or MPI gather is
needed: Eq.~\eqref{eq:ringed_building_block} is evaluated directly from the
already-computed \code{raw/Tmunu\_pervec}.  The momentum list must contain
exactly one \(q=0\) entry when companion output is enabled.

Every repository quark-1pt entry point writes a source-matched companion file
\begin{verbatim}
FlowedQuarkRinged/<lat>.FlowedQuarkRinged.<cfg>.<ama>.<sm>.h5
\end{verbatim}
containing \code{raw/kinetic\_pervec}, source bookkeeping,
\code{avg/kinetic\_spacetime}, and \code{flow\_times}.  It deliberately omits
the two \code{avg/Z\_ring} datasets: a factor computed from a single
configuration is not the final ensemble normalization.

For configuration \(c\), the stored spacetime average is
\begin{equation}
  K_c(\Tf)=\frac{1}{N_{\mathrm{eff}}N_t}
  \sum_{r,\tau}K_{r,c}(\Tf,\tau).
\end{equation}
The analysis must first form the gauge-ensemble mean
\begin{equation}
  K_{\mathrm{code}}(\Tf)=\left\langle K_c(\Tf)\right\rangle_{\mathrm{cfg}},
  \label{eq:ringed_k_code}
\end{equation}
and only then, for a single-flavor trace in fundamental \(SU(3)\), evaluate
\begin{equation}
  Z_{\mathrm{ring}}^{(f)}(\Tf)
  =
  \frac{-2N_c}
       {(4\pi)^2 \Tf^2 K_{\mathrm{code}}^{(f)}(\Tf)}.
  \label{eq:ringed_z_single_flavor}
\end{equation}
In particular,
\(\left\langle 1/K_c\right\rangle_{\mathrm{cfg}}\neq
1/\left\langle K_c\right\rangle_{\mathrm{cfg}}\) in general, so
configuration-local inverse factors must not be averaged.
If instead the kinetic expectation value has already been summed or averaged
over \(N_f\) degenerate flavors, the numerator and denominator must use the same
flavor convention.  A quark EMT bilinear made from ringed fields receives one
factor \(Z_{\mathrm{ring}}\), because the square roots from \(\chi\) and
\(\bar\chi\) multiply to this single bilinear factor.  The \(\Tf=0\) output step
is kept as an unflowed diagnostic and must be excluded from Eq.~\eqref{eq:ringed_z_single_flavor}.
The standalone \code{application/flowed\_quark\_ringed\_norm} workflow remains
available for dedicated high-statistics, spin--color dilution, interval-block,
and resume calculations.

\subsection{Gradient-Flow Schedule for Quarks}

The quark workflow measures before flowing.  Therefore step \(0\) is the
unflowed observable.  If \(\epsilon=\code{flow\_epsilon}\), then
\begin{equation}
  \Tf(n) = n\,\epsilon,
  \qquad
  n=0,\ldots,\code{flow\_steps}.
\end{equation}
The first flow interval is internally split into ten smaller updates:
\begin{verbatim}
for step in range(Nsteps + 1):
    measure Tmunu and CHI
    if step == 0:
        flow [xi, eta] for 10 substeps of stepsize/10
    elif step < Nsteps:
        flow [xi, eta] for 1 step of stepsize
\end{verbatim}
The stochastic source \(\xi\) and solution \(\eta\) are flowed together as one
\code{MultiField}.  This keeps both fields on the same flowed gauge background.
After all flow steps are measured, the code extracts
\code{raw/kinetic\_pervec} algebraically from the stored \(q=0\) diagonal
tensor entries and writes the kinetic companion on MPI rank zero.

\subsection{Four-Dimensional Fermion Flow and the Time-Slice Projector}
\label{sec:full_volume_flow_source}

Let \(K(\Tf)\) denote the gauge-covariant fermion-flow kernel from flow time
zero to \(\Tf\).  Suppressing source labels, the fields measured by the code
are
\begin{equation}
  \xi_f = K(\Tf)\xi,
  \qquad
  \eta_f = K(\Tf)D^{-1}\xi.
  \label{eq:flowed_noise_solution}
\end{equation}
The fermion flow is four dimensional: its covariant Laplacian couples all four
Euclidean directions, including time.  Its characteristic smoothing radius is
approximately \(\sqrt{8\Tf}\).  This radius is a diffusion scale, not a strict
compact-support boundary.

Let \(P_\tau\) project the measured output field onto the absolute Euclidean
time slice \(\tau\), while leaving spatial, spin, and color indices unchanged.
For an EMT kernel \(\Gamma\) on the flowed gauge background, one stochastic
measurement can be written as
\begin{align}
  \widehat L(\tau,\Tf)
  &=
  \xi_f^\dagger P_\tau\Gamma\eta_f
  \nonumber\\
  &=
  \xi^\dagger K^\dagger(\Tf)P_\tau\Gamma
  K(\Tf)D^{-1}\xi.
  \label{eq:flowed_timeslice_estimator}
\end{align}
Using the full-volume noise identity in Eq.~\eqref{eq:noise_identity},
\begin{align}
  \mathbb{E}_\xi[\widehat L(\tau,\Tf)]
  &=
  \Tr\!\left[
    K^\dagger(\Tf)P_\tau\Gamma K(\Tf)D^{-1}
  \right]
  \nonumber\\
  &=
  \Tr\!\left[
    P_\tau\Gamma K(\Tf)D^{-1}K^\dagger(\Tf)
  \right].
  \label{eq:flowed_timeslice_trace}
\end{align}
The projector \(P_\tau\) means that the physical observable remains a spatial
sum at a resolved insertion time; Eq.~\eqref{eq:flowed_timeslice_trace} is not a
sum over insertion time.  Nevertheless, the initial source must cover the full
four-dimensional vector space because \(K^\dagger P_\tau\Gamma K D^{-1}\)
connects the measured time slice to source components at other times.

Equivalently, define
\begin{equation}
  A_\tau = K^\dagger(\Tf)P_\tau\Gamma K(\Tf)D^{-1}.
\end{equation}
For finite noise count, the off-diagonal stochastic contribution is
\begin{equation}
  \widehat L(\tau,\Tf)-L(\tau,\Tf)
  =
  \sum_{i\ne j}\xi_i^*(A_\tau)_{ij}\xi_j.
  \label{eq:flowed_timeslice_noise}
\end{equation}
The left index is constrained by the flowed time-slice operator, but the right
index can originate from any Euclidean time.  These terms vanish in the noise
expectation; their finite-sample size is a variance question.

\subsection{Why a Single Initial-Time Projector Is Not the Current Estimator}

Suppose one replaces the full-volume source by only one time-diluted source
\(\xi_d=P_d\xi\).  At nonzero flow time its expectation value is
\begin{equation}
  \mathbb{E}_\xi\!\left[
    \xi^\dagger P_d K^\dagger P_\tau\Gamma K D^{-1}P_d\xi
  \right]
  =
  \Tr\!\left[
    P_d K^\dagger P_\tau\Gamma K D^{-1}P_d
  \right],
  \label{eq:single_time_projector}
\end{equation}
which is generally not Eq.~\eqref{eq:flowed_timeslice_trace}.  Four-dimensional
fermion flow spreads the endpoint time slice over several initial-time
components, so choosing only \(d=\tau\) omits contributions.

Time dilution is not invalid in principle.  For a complete orthogonal family
\begin{equation}
  \sum_d P_d = \mathbf{1},
  \qquad
  P_dP_{d'}=\delta_{dd'}P_d,
\end{equation}
summing all diluted estimators reconstructs the full trace:
\begin{equation}
  \sum_d
  \Tr\!\left[P_dA_\tau P_d\right]
  =
  \Tr A_\tau.
  \label{eq:complete_time_dilution}
\end{equation}
It requires all projectors and additional inversions.  The present EMT workflow
therefore uses one full-volume base source per stochastic solve and retains all
absolute insertion times.  In the unflowed limit \(\Tf=0\), where
\(K(0)=\mathbf{1}\), a local loop at \(\tau\) can be obtained from the matching
exact-time projector; this special case does not justify dropping the other
projectors for the finite-flow measurements stored in the same file.

\section{Hierarchical Probing and Source Bookkeeping}

The quark one-point workflow supports
\begin{equation}
  \code{noise\_scheme}\in
  \{\code{zn},\code{hierarchical\_probing}\}.
\end{equation}
Hierarchical probing starts from a full-volume base noise vector \(\xi_b\) and multiplies it
by deterministic site-only Rademacher vectors \(h_k(x)=\pm 1\):
\begin{equation}
  \xi_{b,k}(x) = h_k(x)\,\xi_b(x).
  \label{eq:hp_source}
\end{equation}
The probing vectors are designed to reduce near-diagonal contributions to the
stochastic trace variance.  In the current implementation the number of HP
vectors must be a positive power of two:
\begin{equation}
  \code{hp\_num\_vectors}=1,2,4,8,\ldots .
\end{equation}

The effective number of inversions is
\begin{equation}
  N_{\mathrm{eff}}
  =
  \begin{cases}
    \code{n\_vec}, &
    \code{noise\_scheme=zn},\\
    \code{n\_vec}\times\code{hp\_num\_vectors}, &
    \code{noise\_scheme=hierarchical\_probing}.
  \end{cases}
  \label{eq:n_eff}
\end{equation}
This value is stored as \code{effective\_n\_inversions}.

\subsection{Ordering Choices}

Four HP orderings are currently implemented:
\begin{center}
\begin{tabular}{ll}
\toprule
Ordering & Meaning \\
\midrule
\code{global\_xyzt\_gray\_projected\_to\_evenodd}
& Gray-code the full \(x,y,z,t\) site id. \\
\code{interleaved\_xyzt\_binary\_projected\_to\_evenodd}
& Interleave binary bits from \(x,y,z,t\). \\
\code{interleaved\_xyz\_binary\_projected\_to\_evenodd}
& Interleave only spatial bits; the HP sign is time independent. \\
\code{spatial\_xyz\_then\_t\_gray\_projected\_to\_evenodd}
& Gray-code spatial sites first, then append time bits. \\
\bottomrule
\end{tabular}
\end{center}
For the spatial ordering,
\begin{equation}
  h_k(x,y,z,t)=h_k(x,y,z),
\end{equation}
whereas a four-dimensional ordering has signs that also vary with \(t\).  Both
cases multiply the same full-volume base noise and remain nonzero on every time
slice; neither is time dilution.  Spatial HP devotes all available probing bits
to spatial locality, while isotropic 4D HP can suppress temporal off-diagonal
noise at the cost of allocating fewer early bits to space.  Their efficiency is
observable dependent and should be compared at fixed inversion cost.

\subsection{Bookkeeping Datasets}

For each effective source, the output records:
\begin{center}
\begin{tabular}{ll}
\toprule
Dataset & Meaning \\
\midrule
\code{raw/source\_index}
& Effective source index after HP expansion. \\
\code{raw/base\_noise\_index}
& Original base noise index. \\
\code{raw/hp\_index}
& HP vector index used for that base noise. \\
\bottomrule
\end{tabular}
\end{center}
For example, with \(\code{n\_vec}=1\) and
\(\code{hp\_num\_vectors}=2\), the expected bookkeeping is
\begin{equation}
  \code{source\_index}=[0,1],
  \qquad
  \code{base\_noise\_index}=[0,0],
  \qquad
  \code{hp\_index}=[0,1].
\end{equation}

\section{Quark HDF5 Layout}

The quark writer is \code{save\_emt\_quark\_1pt\_hdf5}.  The main raw datasets
are
\begin{align}
  \code{raw/Tmunu\_pervec}
  &:
  [N_{\mathrm{eff}},4,4,N_q,N_{\mathrm{steps}}+1,N_t],
  \\
  \code{raw/CHI\_pervec}
  &:
  [N_{\mathrm{eff}},2,N_q,N_{\mathrm{steps}}+1,N_t].
\end{align}
The averaged datasets are
\begin{align}
  \code{avg/Tmunu/T11},\code{T12},\ldots,\code{T44}
  &:
  [N_q,N_{\mathrm{steps}}+1,N_t],
  \\
  \code{avg/CHI}
  &:
  [2,N_q,N_{\mathrm{steps}}+1,N_t].
\end{align}
Only \(\mu\leq\nu\) tensor components are written in the averaged
\code{avg/Tmunu} group.

The canonical loop file is source independent:
\begin{center}
  \code{EMTc/<lat>.EMTc.<cfg>.<ama>.<sm>.h5}.
\end{center}
It stores every absolute insertion time and is reused for all hadron two-point
source times on the same configuration.

The source-matched kinetic companion is
\begin{center}
  \code{FlowedQuarkRinged/<lat>.FlowedQuarkRinged.<cfg>.<ama>.<sm>.h5}.
\end{center}
Its kinetic-only schema is
\begin{verbatim}
flow_times
raw/kinetic_pervec
raw/source_index
raw/base_noise_index
raw/hp_index
raw/spin_index
raw/color_index
avg/kinetic_spacetime
\end{verbatim}
The spin and color indices are \(-1\) because EMT uses full spin--color noise
rather than point spin--color dilution.  Attributes
\code{producer=emt\_quark\_1pt}, \code{content=kinetic\_only}, and
\code{ringed\_factors\_stored=False} distinguish this subset from a full
standalone output.  The counter-noise configuration, stream, algorithm, HP
ordering, Dirac parameters, gauge preprocessing, boundary condition, flow
schedule, and exact EMT-to-kinetic relation are recorded alongside it.

\subsection{Base-Oriented Production, Checkpoints, and Finalization}

The production wrapper defaults to \code{output\_mode=base\_shards}.  A base
noise and all of its hierarchical-probing vectors form the natural complete
estimator unit,
\begin{equation}
  L_b=\frac{1}{N_{\mathrm{HP}}}\sum_{h=0}^{N_{\mathrm{HP}}-1}L_{b,h}.
\end{equation}
Inside one base the code writes fixed solve intervals, defaulting to 64
inversions.  Thus HP256 normally produces four part files, while HP16 and plain
\(\mathbb Z_4\) produce one.  A partial HP part is a recovery checkpoint and is
not marked as a complete estimator.

Part names encode the base, part, and HP interval, for example
\begin{verbatim}
<canonical-stem>.base000003.part0001.hp0064-0127.h5
\end{verbatim}
Only MPI rank zero writes HDF5.  Each part is first written to a unique temporary
path and then atomically renamed.  Resume reopens existing parts and validates
their physics metadata, shapes, and source indices; compatible parts are
skipped, while conflicting or corrupt files cause an error.  A base completion
marker is published only after every expected part has been revalidated.

Measurement jobs do not update the canonical file.  A separate serial
finalizer requires complete coverage of bases \(0,\ldots,N_{\mathrm{base}}-1\),
streams the raw datasets into a temporary canonical EMTc file, accumulates the
averages without holding the complete source axis in memory, and derives the
kinetic companion from the \(q=0\) diagonal tensor.  The completed companion is
published before the canonical EMTc file, so downstream analysis never sees a
new loop without its matching kinetic data.  Non-overlapping base ranges may be
scheduled independently; overlapping jobs are unsupported.

One runtime detail is essential: evaluating a flowed contraction loads the
flowed gauge into QUDA's global resident gauge state.  Before inverting the next
stochastic source, the code therefore reloads the original unflowed input gauge.
The input Python gauge object is unchanged, but omitting this resident-state
restore makes later inversions use the wrong gauge and can trigger precision
mismatch failures.

\section{Gluon One-Point Workflow}

The gluon workflow is independent of stochastic quark sources.  It constructs a
flowed gauge-field strength and then measures a spatially Fourier-projected
gluon EMT building block.

\subsection{Clover Field Strength}

For each independent plane \((\mu,\nu)\), the code constructs the four oriented
clover plaquettes
\begin{align}
  &\mu \to \nu \to -\mu \to -\nu, \\
  &\nu \to -\mu \to -\nu \to \mu, \\
  &-\mu \to -\nu \to \mu \to \nu, \\
  &-\nu \to \mu \to \nu \to -\mu.
\end{align}
Let \(Q_{\mu\nu}(x)\) be their sum.  The anti-Hermitian clover field is
\begin{equation}
  A_{\mu\nu}(x)
  =
  \frac{1}{8}
  \left[
    Q_{\mu\nu}(x)-Q_{\mu\nu}^\dagger(x)
  \right].
  \label{eq:clover_A}
\end{equation}
The code projects this matrix to the traceless \(\mathfrak{su}(3)\) algebra:
\begin{equation}
  A^{\mathrm{tl}}_{\mu\nu}(x)
  =
  A_{\mu\nu}(x)
  -
  \frac{1}{N_c}
  \Trc[A_{\mu\nu}(x)]\,\mathbf{1}.
  \label{eq:clover_traceless}
\end{equation}
Finally, the Euclidean field-strength convention used by the implementation is
\begin{equation}
  F_{\mu\nu}(x) = -i\,A^{\mathrm{tl}}_{\mu\nu}(x).
  \label{eq:F_euclidean}
\end{equation}
Only the six independent planes are computed, and the antisymmetric entries are
filled with
\begin{equation}
  F_{\nu\mu}(x) = -F_{\mu\nu}(x).
\end{equation}
The traceless projection is a field-strength projection.  It is not a
traceless projection of the final EMT tensor.

\subsection{Implemented Gluon EMT Loop}

The implemented gluon one-point building block is
\begin{equation}
  L^g_{\mu\nu}(q,t;\Tf)
  =
  \frac{2}{\Vthree}
  \sum_{\mathbf{x}}\Phi_q(x)
  \sum_{\substack{\rho=1\\ \rho\ne\mu,\nu}}^{4}
  \Trc\!\left[
    F_{\mu\rho}(x;\Tf)\,
    F_{\nu\rho}(x;\Tf)
  \right].
  \label{eq:gluon_loop}
\end{equation}
This maps directly to the code in \code{EMTDisconnectedGluon1pt.flowed\_1pt}:
\begin{verbatim}
for mu in range(4):
    for nu in range(mu, 4):
        tmp = zeros(...)
        for rho in range(4):
            if rho == mu or rho == nu:
                continue
            tmp += contract("...ab,...ba->...", F[mu][rho], F[nu][rho])
        Tmunu_t[mu, nu, :, step, :] += 2.0 * slice_t
Tmunu_t /= Ns3
\end{verbatim}
The factor \(2\) is explicit in the code.  The division by \(\Vthree\) is
applied after all spatial Fourier sums have been accumulated.

\subsection{Gradient-Flow Schedule for Gluons}

As in the quark workflow, step \(0\) is measured before flow and therefore is
the unflowed gauge observable.  After each measurement, the gauge field is
advanced by Wilson or Symanzik flow:
\begin{verbatim}
for step in range(Nsteps + 1):
    measure F and Tmunu
    if step == 0:
        flow gauge for 10 substeps of stepsize/10
    elif step < Nsteps:
        flow gauge for 1 step of stepsize
\end{verbatim}

\section{Disconnected Combination with Proton Two-Point Functions}

The quark and gluon one-point loops are hadron independent.  They become a
proton disconnected three-point building block only after being correlated with
the proton two-point function on the gauge ensemble.  For a proton two-point
function \(C_2^p(p_f,t)\), define
\begin{equation}
  C^{p,\mathrm{disc}}_{3,\mu\nu}
  (p_f,p_i;t,\tau;\Tf)
  =
  \left\langle
    C_2^p(p_f,t)\,
    L_{\mu\nu}(q,\tau;\Tf)
  \right\rangle_{\mathrm{cfg}}
  -
  \left\langle C_2^p(p_f,t)\right\rangle_{\mathrm{cfg}}
  \left\langle L_{\mu\nu}(q,\tau;\Tf)\right\rangle_{\mathrm{cfg}},
  \label{eq:disc_C3}
\end{equation}
with
\begin{equation}
  q=p_f-p_i.
\end{equation}
The subtraction term removes the vacuum expectation value of the one-point
loop.  This subtraction must be done at the ensemble-analysis level using the
same configuration set as the proton two-point function.

A basic ratio is
\begin{equation}
  R^{p,\mathrm{disc}}_{\mu\nu}(t,\tau;\Tf)
  =
  \frac{
    C^{p,\mathrm{disc}}_{3,\mu\nu}(p_f,p_i;t,\tau;\Tf)
  }{
    C_2^p(p_f,t)
  }.
  \label{eq:disc_ratio}
\end{equation}
Kinematic projectors, EMT mixing coefficients, and gradient-flow matching
factors are applied later in the physics analysis.

\section{End-to-End Proton Diagnostic Workflow}

The application directory
\begin{center}
  \code{application/EMT\_disconnected\_1pt/perlmutter}
\end{center}
contains a minimal four-step diagnostic workflow:
\begin{enumerate}
  \item measure the stochastic quark one-point loop;
  \item measure the gluon one-point loop;
  \item measure the proton two-point function \(C_2^p\);
  \item combine \(C_2^p\) and the one-point loops into disconnected diagnostic
        three-point objects.
\end{enumerate}

For the quark loop, the builder reads \code{raw/Tmunu\_pervec} and forms
cumulative stochastic averages
\begin{equation}
  \overline{L}^{q,N}_{\mu\nu}(q,t;\Tf)
  =
  \frac{1}{\Vthree}
  \frac{1}{N}
  \sum_{r=1}^{N}
  L^{q,(r)}_{\mu\nu}(q,t;\Tf),
  \qquad
  N=1,\ldots,N_{\mathrm{eff}}.
  \label{eq:cumulative_loop}
\end{equation}
This is the quantity used to check whether the stochastic estimator changes
smoothly as more random sources are included.

For a single configuration, the builder can only form the unsubtracted proxy
\begin{equation}
  C^{\mathrm{unsub},N}_{3,\mu\nu}
  (t_{\mathrm{sep}},q,t;\Tf)
  =
  C_2^p(t_{\mathrm{sep}})\,
  \overline{L}^{q,N}_{\mu\nu}(q,t;\Tf).
  \label{eq:single_cfg_proxy}
\end{equation}
This object is useful for checking shapes, source-count dependence, time
alignment, and HDF5 plumbing.  It is not the physical disconnected correlator,
because the vacuum subtraction in Eq.~\eqref{eq:disc_C3} requires an ensemble
average.

With multiple configurations, the builder applies the ensemble subtraction for
each cumulative source count:
\begin{align}
  C^{\mathrm{disc},N}_{3,\mu\nu}
  &=
  \left\langle
    C_2^p\,\overline{L}^{q,N}_{\mu\nu}
  \right\rangle_{\mathrm{cfg}}
  -
  \left\langle C_2^p \right\rangle_{\mathrm{cfg}}
  \left\langle
    \overline{L}^{q,N}_{\mu\nu}
  \right\rangle_{\mathrm{cfg}},
  \\
  R^{\mathrm{disc},N}_{\mu\nu}
  &=
  \frac{
    C^{\mathrm{disc},N}_{3,\mu\nu}
  }{
    \left\langle C_2^p \right\rangle_{\mathrm{cfg}}
  }.
  \label{eq:cumulative_ratio}
\end{align}
The gluon loop has no stochastic source axis, so the builder forms the same
unsubtracted and vacuum-subtracted objects without a cumulative \(N\) index.

quark/R_disc_cumulative      # only if Ncfg >= 2

\end{verbatim}

\section{How to Read Smoke Tests}

A single \code{S8T32} test gauge checks implementation conventions, not physics
signals.  Useful smoke-test checks are:
\begin{itemize}
  \item the code runs on the intended backend;
  \item \code{flow\_times} contains step \(0\) and the requested flow times;
  \item \code{upper\_triangle\_only=True};
  \item quark raw datasets have the expected
        \([N_{\mathrm{eff}},4,4,N_q,N_{\mathrm{steps}}+1,N_t]\) and
        \([N_{\mathrm{eff}},2,N_q,N_{\mathrm{steps}}+1,N_t]\) shapes;
  \item HP runs have consistent \code{raw/source\_index},
        \code{raw/base\_noise\_index}, and \code{raw/hp\_index};
  \item gluon datasets contain \code{Tmunu/T11} through \code{T44} but no
        stochastic \code{raw/Tmunu\_pervec}.
\end{itemize}

\section{Recommended Next Algorithmic Upgrade}

The current variance-reduction options are ordinary \(Z_n\) noise and
hierarchical probing.  A planned future direction is multiplier-based graph
coloring, motivated by
\begin{center}
  \href{https://arxiv.org/abs/2606.00394}{arXiv:2606.00394}.
\end{center}
The motivation is that standard HP naturally tests \(2^k\) source counts,
whereas multiplier-based coloring can test intermediate coloring budgets.  A
future scheme should be added as a separate optional source scheme, with HDF5
metadata that clearly distinguishes it from \code{hierarchical\_probing}.
